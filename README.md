# High Five! 🖐️

Gamified daily task tracker for families — parents manage tasks, and kids check them off on a shared device.

## 📖 About

High Five! helps parents track their children's daily chores and responsibilities in a fun, motivating way. Inspired by Duolingo-style gamification, it features streaks, points, weekly rankings and rewards. Only parents have accounts — children interact through a PIN-locked "Kid View" on a shared device.

## 🛠️ Tech Stack

- **Frontend:** React + Vite ⚡ + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** PostgreSQL (Neon) + Prisma ORM

## 📂 Project Structure

- `client/` → React frontend
- `server/` → Express backend
